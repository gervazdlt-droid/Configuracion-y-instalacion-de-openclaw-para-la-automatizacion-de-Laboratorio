# Política de seguridad

Reporta una exposición de token, una ejecución inesperada o una fuga de datos al responsable del laboratorio. Revoca inmediatamente el token afectado, conserva el log mínimo necesario y documenta el incidente sin volver a publicar el secreto.

Este repositorio no acepta credenciales reales, datos de pacientes, muestras identificables ni resultados restringidos.
